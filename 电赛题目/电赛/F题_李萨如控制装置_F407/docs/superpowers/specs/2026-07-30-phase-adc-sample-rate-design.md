# PA1/PA2分段采样率设计

## 范围

仅修改PA1/PA2同步双ADC在所有相关菜单中的采样率选择。保持1024点采样块、双ADC同步DMA、单频DFT、幅值控制、相位控制和AD9959代码不变。普通ADC、AD7606和ADS1256不在本次范围内。

## 采样策略

根据当前分析频率选择目标采样率：

| 分析频率 | 目标采样率 |
| --- | --- |
| `0 <= f < 10 Hz` | `1024 * f` |
| `10 <= f < 100 Hz` | `256 * f` |
| `100 <= f < 1 kHz` | `64 * f` |
| `1 kHz <= f < 10 kHz` | `16 * f` |
| `10 kHz <= f < 100 kHz` | `8 * f` |
| `100 kHz <= f <= 200 kHz` | `4 * f` |

当前F题输入范围为1至100 kHz，因此实际使用后三档。要求2和要求4按输入频率选择；要求3按输出分析频率`2 * fin`选择，最高覆盖200 kHz。

目标采样率必须限制在`PHASE_ADC_MIN_SAMPLE_RATE_HZ`至`PHASE_ADC_MAX_SAMPLE_RATE_HZ`之间。TIM8使用整数PSC/ARR产生最接近目标的实际采样率，DFT继续读取`PhaseAdc_GetSampleRateHz()`，不能使用未量化的目标值。

## 数据流

`输入频率 -> 菜单对应分析频率 -> 分段倍率 -> 目标Fs -> TIM8实际Fs -> 1024对PA1/PA2样本 -> 单频DFT`

频率档位或实际输入频率改变时，允许重新启动PA1/PA2 ADC；同一频率重复处理时不得反复重启ADC。

## 验证

1. 检查1 kHz、9.9 kHz、10 kHz、99.9 kHz、100 kHz和200 kHz分析频率的目标倍率。
2. 检查TIM8实际采样率不超过1.2 MS/s。
3. 检查每块仍为1024对同步样本，DFT使用实际采样率。
4. 重新编译Keil工程，要求0错误。
5. 确认幅值、相位PI和AD9959目录无修改。

## 非目标

本次变更只替换采样率选择策略，不声称解决当前约40度的ADC测相偏差；该问题需要后续通过原始双通道样本、过零相位和DFT相位对比单独定位。
